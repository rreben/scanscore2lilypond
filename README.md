# scanscore2lilypond

Purges LilyPond files that have been created from ScanScore via MusicXML.

ScanScore is a commercial OMR (optical music recognition) program that analyzes scanned sheet music and generates MusicXML and MIDI files. It has a graphical editor to correct glitches that usually occur during the OMR process.

The MusicXML file can be transformed to LilyPond, a sophisticated text based music engraver. However, the resulting LilyPond file is cluttered with layout instructions that are not helpful for further work.

This is where scanscore2lilypond comes in handy: It purges the resulting lilypond file.

## How to use scanscore2lilypond

`scanscore2lilypond` has to be installed as a Python command line tool (see below). The command supports three workflows.

### Full roundtrip

The full roundtrip starts with a ScanScore MusicXML export, purges the XML, runs LilyPond's `musicxml2ly`, and purges the generated LilyPond file:

```sh
scanscore2lilypond --full Pleyel_Presto_I.xml
```

This creates three files next to the input file:

- `Pleyel_Presto_I_step1.xml`: purged MusicXML
- `Pleyel_Presto_I_step2.ly`: LilyPond file generated by `musicxml2ly`
- `Pleyel_Presto_I_step3.ly`: purged LilyPond file for further editing

The full roundtrip requires LilyPond's `musicxml2ly` command to be installed and available in the terminal.

### Manual two-step workflow

You can still run the individual steps manually. First purge the MusicXML file with the `-x` option:

```sh
scanscore2lilypond -x -o purged_musicxmlfile.xml some_musicxmlfile.xml
```

Then use the `musicxml2ly` program of the LilyPond package:

```sh
musicxml2ly purged_musicxmlfile.xml
```

The resulting `.ly` file can be further improved with:

```sh
scanscore2lilypond purged_musicxmlfile.ly
```

This time we do not use the `-x` option, as we are modifying the LilyPond file directly.

### LilyPond-only purge

If you already have a LilyPond file, run the command without `-x` or `--full`:

```sh
scanscore2lilypond -o clean_score.ly raw_score.ly
```

Without `--output`, the result of a single purge process will be printed to stdout.

Help is available with:

```sh
scanscore2lilypond --help
```

## How to install scanscore2lilypond

Right now scanscore2lilypond is still in alpha. So we have to install the file locally.

Clone the repository:

```sh
git clone https://github.com/rreben/scanscore2lilypond
cd scanscore2lilypond
```

For local development, create a virtual environment and install the package in editable mode:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

For daily use from any terminal, install it into a dedicated user venv and expose the command through `~/.local/bin`:

```sh
python3 -m venv ~/.local/share/scanscore2lilypond-venv
~/.local/share/scanscore2lilypond-venv/bin/python -m pip install -e .
mkdir -p ~/.local/bin
ln -sf ~/.local/share/scanscore2lilypond-venv/bin/scanscore2lilypond ~/.local/bin/scanscore2lilypond
```

Make sure `~/.local/bin` is in your shell path. For zsh, add this to `~/.zprofile`:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

Then open a new terminal, or run:

```sh
source ~/.zprofile
rehash
```

The following command can be used to view the metadata of the library:

```sh
~/.local/share/scanscore2lilypond-venv/bin/python -m pip show scanscore2lilypond
```
